Hardened NGINX Distribution

Your traffic is served by a minimal, verified container image configured with defense-in-depth defaults.

Security Features

  • Content delivered with strict security headers (CSP, HSTS, COOP/COEP, CORP).
  • Nginx runs as an unprivileged user on a high port to avoid root access.
  • Requests limited to safe HTTP verbs and hardened buffer limits.

Supply Chain Integrity

The published Docker image is signed with Sigstore Cosign. Verify before deploying:

cosign verify docker.io/brandenp88/nginx-secure:latest
